# Machine Pre-code Notice

`machine_precode.json` is a conservative heuristic triage generated from commit
terms, changed paths, and candidate test paths. It is not a human annotation,
does not verify any defect, and is excluded from agreement, corpus counts,
Operator derivation, and held-out mapping analysis.

This directory must not be included in the H1 or H2 coding package. The file may
be inspected only after both raw human Pass A submissions have been validated,
hashed, and frozen.
